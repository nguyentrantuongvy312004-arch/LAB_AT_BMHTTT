LAB 7: XÂY DỰNG CHÍNH SÁCH WEB PROTECTION TRÊN MÔ HÌNH PFSENSE + WEB PROXY, Nguyễn Trần Tường Vy_11_TTMT_1150070051. Môi trường thực hiện Lab 7 được xây dựng trên phần mềm ảo hóa VirtualBox, sử dụng pfSense làm tường lửa và cổng kết nối giữa các mạng. Hệ thống bao gồm Windows Server (DC01) đảm nhiệm dịch vụ DNS và Active Directory, các máy khách Client-A và Client-B dùng để kiểm tra chính sách truy cập web, máy chủ WEB-PROXY chạy Ubuntu Server 24.04 LTS để triển khai Squid, E2Guardian và ClamAV, cùng máy chủ DMZ-WEB để cung cấp các trang web mô phỏng phục vụ kiểm thử. Các thành phần được cấu hình địa chỉ IP và kết nối trong mạng LAN, DMZ phù hợp nhằm kiểm tra khả năng lọc nội dung web, chặn truy cập trực tiếp, cảnh báo và cho phép truy cập tạm thời, quản lý thời gian truy cập và quét mã độc.
